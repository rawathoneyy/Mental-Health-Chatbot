# Saanjh – Mental Wellness Support Chatbot

A calming frontend interface for a mental wellness chatbot that provides users a safe space to talk and express their feelings through text and voice.

> **Team Project**

---

## Overview

Saanjh is a mental wellness support chatbot interface built to offer a peaceful and non-judgmental space for users.  
The frontend was developed using modern web technologies, while the conversational AI is powered by **Botpress Cloud**.

---

## Features

- Clean and calming user interface
- Text-based chat support
- Voice input support
- Responsive design
- Integration with Botpress Cloud conversational AI
- Built as part of a team project

---

## Tech Stack

- **Frontend:** Next.js, React, Tailwind CSS, shadcn/ui
- **Chatbot Engine:** Botpress Cloud
- **Deployment:** GitHub

---

## My Contribution

- Built the frontend for the mental wellness chatbot using Next.js, React, and Tailwind CSS with a shadcn/ui component system
- Integrated Botpress Cloud’s hosted conversational AI platform to power text- and voice-based chat interactions
